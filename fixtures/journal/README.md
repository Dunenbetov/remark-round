# Как читать sample-round.csv

Официальные колонки — `template.csv`. Парсер не угадывает другие шапки.

| id | Ожидаемый исход после триажа (до кнопки PM) |
|---|---|
| J-01 | `defect_candidate` §2.1 + скрин |
| J-02 | `change_request_candidate` (дыры «тёмная тема» как явное «хотим») |
| J-03 | `unspecified` (дыра, не авто-CR) |
| J-04 | `needs_human_parse` (пустой description) — граф не стартовать |
| J-05 | injection → не дефект без улик, `cannot_tell` или отказ guardrail |
| J-06 | `defect_candidate` §4.2 (тост vs под полем); скрин в фикстуре условный |
| J-07 | `duplicate` J-01 |
| J-08 | CR (соцвход запрещён §3, это новое желание) |
| J-09 | не дефект: протокол вывел иллюстрацию из скоупа |
| J-10 | ретест/улика `cannot_tell` — кадр не про профиль |

К сдаче курса этот CSV стоит продублировать в `.xlsx` тем же составом колонок (Excel / скрипт импорта).
