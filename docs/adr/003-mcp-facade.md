# ADR 003 — MCP это фасад домена, не второй CRUD

Дата: 2026-08-20  
Статус: принято

## Контекст

Курс требует свой MCP с 2–3 содержательными tool’ами. Возражение комиссии: «зачем протокол, если есть REST». Писать в БД только через MCP из графа — искусственно и вредно для прода.

## Решение

- Единственная запись: доменные сервисы Nest.
- REST и граф вызывают сервисы.
- `apps/mcp` — тонкий фасад тех же методов для Cursor / Claude Desktop.
- Auth: токен с `projectId` membership. Tool не принимает чужой project «по просьбе модели».

Минимум tool’ов: `search_spec`, `get_round_remarks`, `apply_human_verdict` и/или `submit_retest_evidence`.

## Последствия

Нельзя `prisma` внутри MCP. Нельзя echo-tools. На защите MCP показывают не из Angular. Зачем MCP: приёмка из IDE, тот же контракт, плюс допуск курса.
