# Что смотреть из курса к защите

Список для владельца, 18.09.2026. Он пропустил занятия с модуля RAG (модули 4–7), а менторы на защите — те же люди, что читали эти лекции, и спрашивают их словами. Порядок — по пользе для защиты RemarkRound: вес критерия × насколько тема есть в проекте × вероятность вопроса. Содержание лекций известно только по названиям — «что искать» сформулировано как вопросы, на которые после просмотра нужно уметь ответить про **наш** проект.

Как смотреть: скорость 1.25–1.5×, рядом открыт файл нашего проекта из колонки «У нас». После лекции — три ответа своими словами вслух; непонятное — спросить агента «как это устроено у нас».

Почему наша faithfulness — правила, а не LLM-судья (детерминированно, бесплатно, работает в CI), и что она пропускает (смысловую неверность пересказа). |
