## 6. Заметки для агентов

- **Тесты API**: перед `pnpm --filter @remarkround/api test` выполнить `docker compose stop api mcp` (работающий воркер крадёт задачи тестов), после — `docker compose start api mcp`. Jest не должен видеть `OPENAI_API_KEY` (`test/setup.ts` его удаляет). Упавший `afterAll` вешает jest — `--forceExit`.
- **Node 24**: `source ~/.nvm/nvm.sh && nvm use 24`. Railway CLI 5.57 стоит под Node 24 (`railway`), проект привязан к папке репозитория.
- **CI YAML**: имя шага с `: ` внутри — только в кавычках. Из-за этой ошибки CI не запускался с 07.09 по 17.09. Проверка: js-yaml из `node_modules/.pnpm/js-yaml@4*/`.
- **Railway**: настройки сервиса применяются только кнопкой **Deploy** в панели, иначе остаются черновиком. Секреты вводит владелец, агент их не читает и не выводит; проверять можно через `railway run --service api -- sh -c '…'`, не печатая значения. Регион сервиса IaC менять не умеет — только `serviceInstanceUpdate` через `railway api`.
- **Модель и промпты**: изменения в `skills/uat-triage/SKILL.md` и промптах меняют цифры evals. Делать их только в этапе 1 и до M1.
- **Язык**: доки и тексты интерфейса по-русски, без детективной лексики («улика», «дело», «судья», «вердикт»).
- **Миграции**: писать руками в `packages/db/prisma/migrations/<ts>_<slug>/migration.sql`, затем `pnpm --filter @remarkround/db migrate:deploy && pnpm db:generate && pnpm --filter @remarkround/db build`. С 21.09 — только добавляющие (см. раздел 2).
