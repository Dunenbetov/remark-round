## 6. Заметки для агентов

Секреты вводит владелец, агент их не читает и не выводит; проверять можно через `railway run --service api -- sh -c '…'`, не печатая значения. Без `REMARKROUND_PASSWORD` или `REMARKROUND_TOKEN` сервер сразу выходит с понятным сообщением — сессии это не мешает; отключить у себя — `disabledMcpjsonServers` в `.claude/settings.local.json`.
- **Офлайн-evals локально**: раннер `pnpm evals` не читает `.env` сам (в отличие от jest) — нужны `DATABASE_URL` из `.env`, любой `JWT_SECRET` и `LANGFUSE_TRACING_ENABLED=false`, без `OPENAI_API_KEY`. Базовая линия 19.09: binding 23/33, faithfulness 33/33, hit@1/3/6 20/25/25, ретест 12/15.
- **Нестабильный тест**: 19.09 `verdict.model-cannot-close.spec` один раз упал в полном прогоне (`socket hang up` в первом тесте, второй — следом); отдельно и в трёх следующих полных прогонах — зелёный. Если повторится в CI — перезапустить job, затем разбираться.
- **Mermaid** проверять до коммита: `mermaid.parse` и `render` из `cdn.jsdelivr.net/npm/mermaid@11` во встроенном браузере.
- **Миграции**: писать руками в `packages/db/prisma/migrations/<ts>_<slug>/migration.sql`, затем `pnpm --filter @remarkround/db migrate:deploy && pnpm db:generate && pnpm --filter @remarkround/db build`. С 21.09 — только добавляющие (см. раздел 2).
- **Честные пункты для защиты** — в [HONEST-NOTES.md](HONEST-NOTES.md) (просьба владельца 21.09): нашли ограничение, неподтвердившуюся гипотезу или ошибку, пойманную замером, — допишите пункт сразу, в формате файла (что · доказательство · что сделали · как сказать · критерий).
- **Раннер evals выходит с кодом 1, когда сработал порог качества** (injection → defect, faithfulness, leakage). В CI это красный билд, в замерах — данные: успех прогона = есть отчёт `.md`. Скрипты сессий — `evals/results/2026-09-20-m1-session.sh`, `2026-09-21-wish-ab.sh` (продолжают с места, пропуская готовые отчёты).
- **Правка промпта или Skill — только с A/B**: 21.09 три «очевидные» починки на 70 прогонах каждая ухудшали соседние кейсы (HONEST-NOTES, п. 1). Отчёт раннера пишет sha и «+правки» при грязном дереве — перед замером коммитить.
