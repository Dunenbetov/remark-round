# ANTI.md — если сделал, удали до ревью

UI-клоны, которые агент рисует «по привычке». В RemarkRound это баги.

## Продукт не тот

- [ ] Канбан To Do / In Progress / Done
- [ ] Поля Assignee, Sprint, Story points, Epic, Labels
- [ ] Плавающий пузырь «Спросить ИИ»
- [ ] Общий чат без `remarkId`
- [ ] Онбординг из 8 шагов про RAG и эмбеддинги
- [ ] Виджет-пин на чужом стенде
- [ ] Тёмная тема как отдельная вёрстка (тёмная есть, но только через токены `[data-theme]`; светлая остаётся основной)
- [ ] Страница «AI playground» / выбор модели для бизнеса

## Чат и IDE

- [ ] Пузыри сообщений user/assistant
- [ ] Поле «Напишите сообщение…» как в ChatGPT
- [ ] Стрим токенов на весь экран, курсор ▊ как в Cursor
- [ ] Бейдж GPT / Claude / «powered by»
- [ ] «Уверенность 87%»
- [ ] Заголовок «Copilot», «Assistant», «Agent reply»

## Админка из коробки

- [ ] Angular Material **дефолтный фиолетовый** `prebuilt-theme`
- [ ] Плотная таблица Jira: 12 колонок, мелкий шрифт
- [ ] Сайдбар на 14 пунктов
- [ ] Карточка = один узкий столбец по центру «как мессенджер»

## Слова на экране (запрещены)

Approve, Reject, Submit ticket, Backlog, Sprint, Board, Workflow, Binding, Retrieval, HITL, LangGraph, RAG, Prompt, Fine-tune, Confidence.

## Визуальный канон «Arc · Индиго» (нарушения — тоже баги)

- [ ] Второй залитый индиго-объект на экране (кроме primary-кнопки): рельс ИЛИ тайл «Ждут вас» ИЛИ поднос «В работе» — что-то одно
- [ ] Аква как фон кнопки или текст на белом (аква живёт только на индиго и как маркер; текст — `--rr-accent-2-text`)
- [ ] Цветные точки у каждого статуса (точка — только пульс «разбираем»; статус читается словом)
- [ ] Рамка + заливка + тень на одном блоке внутри карточки (внутри бумаги — только тонированные блоки без рамки)
- [ ] Подсказка-строка «что здесь происходит» в потоке страницы (объясняет тур, не лейаут)
- [ ] Схема «Как идёт замечание» на журнале (живёт в туре; на карточке — одна строка слов)
- [ ] Капс-ярлыки с разрядкой где-то кроме заголовков колонок
- [ ] Медь, сосна, бумажный сериф — прошлый канон, не возвращать
- [ ] Unbounded в абзацном тексте (только цифры и wordmark)

## Поведение

- [ ] Автовыбор вердикта с тостом «уже отправили разработчикам»
- [ ] Вердикт, закрытие или «Готово» без окна «Отменить» (5 секунд, `PendingActionService`)
- [ ] Печать черновика по словам и таймеры «для красоты»: фазы показываются, пока сервер реально разбирает
- [ ] Присутствие с выдуманным именем: «Смотрит: …» только из presence комнаты WS
- [ ] Кнопка Закрыть у разработчика или у модели
- [ ] Спиннер на всю карточку без фазовой строки
- [ ] Скрин как иконка 48px в аттачах — он должен быть главным
