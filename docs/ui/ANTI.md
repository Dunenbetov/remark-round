- [ ] Яркая заливка поверх индиго (аква, неон, цветной ореол) и цветной маркер как фон кнопки на белом: на индиго маркер белый, активный пункт рельса — стекло; на белом — тил `--rr-accent-2-text` / `-soft`
- [ ] Цветные точки у каждого статуса (точка — только пульс «разбираем»; статус читается словом)
- [ ] Рамка + заливка + тень на одном блоке внутри карточки (внутри бумаги — только тонированные блоки без рамки)
- [ ] Радиус вне трёх ступеней 24 / 14 / 8 — и ступень не по вложенности (лист внутри бумаги не бывает круглее бумаги)
- [ ] Подложка под панелью «Ваше решение» и вообще третий уровень контейнера внутри карточки (плашка внутри кнопки внутри панели)
