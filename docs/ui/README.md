| Файл | Зачем |
|---|---|
| [`COPY.md`](COPY.md) | Все надписи дословно |
| [`VISUAL.md`](VISUAL.md) | Роли токенов, закон маркера, иерархия экранов, движение, адаптив |
| [`ANTI.md`](ANTI.md) | Что удалить, если агент нарисовал Jira/чат или вернул прошлый канон |
