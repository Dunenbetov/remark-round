# VISUAL.md — стол с бумагами

Не Linear. Не ChatGPT. Не фиолетовая админка.  
Эталон в браузере: [`reference.html`](reference.html).

## Ощущение

Тёплый бумажный стол, скрин как фото доказательства, справа — спокойные кнопки человека. Много воздуха. Можно читать с проектора на защите.

## Токены

Единственный источник — [`apps/web/src/styles/tokens.css`](../../apps/web/src/styles/tokens.css). Роли, не хексы:

| Роль | Зачем |
|---|---|
| `--rr-bg` → `--rr-surface` → `--rr-surface-raised` | фон стола → бумага → меню и полосы |
| `--rr-ink` / `--rr-ink-2` / `--rr-ink-3` | текст / метаданные / подсказки и плейсхолдеры (все ≥ 4.5:1) |
| `--rr-line` / `--rr-line-strong` | hairline / границы полей |
| `--rr-accent` / `--rr-accent-text` / `--rr-accent-soft` | заливка primary / ссылки и активный чип / фон активного чипа |
| `--rr-{wait,work,muted,ok,danger}-{bg,ink,dot}` | статус-пилюли: фон, текст, точка |
| `--sp-1…12`, `--fs-12…28` + `--lh-*`, `--rr-r-{sm,md,lg,xl,pill}` | отступы (4px), типографика, радиусы |
| `--dur-fast` / `--dur` / `--dur-slow`, `--undo-ms` | движение 120 / 180 / 240 мс, окно отмены 5 с |

Тёмная тема — тот же список ролей в блоке `[data-theme='dark']`; `ThemeService` ставит атрибут (и в режиме «как в системе»). Светлая остаётся основной: скрины с проектора показываем в ней.

Шрифты: **Golos Text** (интерфейс, кириллица-first, variable 400–900) + **Source Serif 4** только для слова RemarkRound. Оба self-hosted из `@fontsource-variable/*` (банковские сети режут CDN). Не Inter «как все SaaS», не Roboto Material. Базовый кегль 15/22 — читается с проектора.

## Иерархия карточки (закон)

Ширина колонок ≈ `1.15fr 1fr 0.85fr`.

1. **Улики** — скрин на всю ширину колонки, зум по клику. На ретесте ряд: было | стало | дифф, дифф не прятать.
2. **Черновик разбора** — цитата ТЗ заметнее стрима. Стрим мельче, цвет `--rr-ink-soft`.
3. **Решение** — одна primary, остальные `background: transparent; border: 1px solid var(--rr-line)`.

Шапка: тонкий липкий бар 56px (RemarkRound · проект · раунд | разделы | «Добавить замечание» · аватар). Роль — **h1 страницы** под баром («Вы решаете, работа ли это»), под ней «Раунд 2 · 13 замечаний, 3 ждут вас». Человек всегда понимает, кто он.

## Компоненты, которые можно

Кнопки (`.btn--busy` — спиннер на месте подписи, ширина не прыгает), чип статуса с точкой, таблица раунда (`<table class="tbl">`, строка-ссылка без вложенных интерактивов), чип-фильтр со счётчиком, `rr-empty-state`, `rr-error-banner` («Повторить» на месте, не тост), `rr-skeleton` (пульс прозрачности, без шиммера), `rr-menu`, фазовая строка в подвале карточки, цитата (слева 3px `--rr-accent-text`).

## Отмена решения

Вердикт PM, «Закрыть: исправлено», «Не исправлено», «Готово, можно смотреть снова» уходят на сервер через 5 секунд. Всё это время на месте кнопок — «Решение: … · Отменить» с полоской. Уход со страницы — коммит сразу. Это не тост про авто-вердикт: решение нажал человек.

## Компоненты, которых нет

FAB-чат, snackbar «AI done», stepper из 7 шагов, dashboard с графиками LLM cost для бизнеса (cost — в EVALS/админ).

## Angular

- Не подключать `indigo-pink.css` / `magenta-violet`.
- Material — только если очень нужно CDK (a11y, overlay). Тема своя, токены выше.
- `strict` templates. Фокус: видимое кольцо на кнопках, не `outline: none` без замены.
- Картинка скрина: `max-width: 100%`, клик → overlay на весь экран (колесо зума — хорошо).

## Адаптив

MVP защиты — **десктоп две колонки минимум**. Узкий экран: улики наверх, черновик, кнопки липко снизу. Не прячь кнопки PM в «⋯».

## Анимация

Фаза и появление черновика — 150–200ms, без «генеративной» волны и градиентного шиммера на полкарточки. Печати по словам нет: черновик уже пришёл из API, он проявляется целиком. Фазы показываются только пока сервер реально в `triaging` (и коротко после «Сохранить» у бизнеса).
