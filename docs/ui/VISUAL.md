# VISUAL.md — «Arc · Индиго»: белая бумага, один цветной объект

Не Linear. Не ChatGPT. Не фиолетовая админка. Не бумажный гроссбух.  
Направление выбрано владельцем 11 сентября 2026 из четырёх макетов (Arc/Raycast + Bento); процесс — по статье Anshu Chimala: seed-строки → макеты → критик-субагент по скриншотам → вырезать лишнее. Живой эталон — само приложение (`apps/web`); `reference.html` и «стол с бумагами» — история.

## Ощущение

Светлый прохладный стол, белая бумага с мягким 3D (тень вниз, блик сверху). Радиус говорит о вложенности, три ступени: **24 → 14 → 8** — что лежит на столе / что лежит на бумаге / метка внутри листа; промежуточных значений нет. На каждом экране ровно один большой цветной объект — индиго: рельс очереди на карточке, плита «Ждут вас» в журнале, поднос «В работе» в очереди разработчика. Маркер «сейчас здесь» на индиго — белый и тихий (стекло), на бумаге — тил. Ничего не объясняет само себя дважды: подсказок-строк и схем в потоке нет, критик их вырезал. Можно читать с проектора на защите.

## Токены

Единственный источник — [`apps/web/src/styles/tokens.css`](../../apps/web/src/styles/tokens.css). Роли, не хексы:

| `--rr-bg` → `--rr-surface-2` → `--rr-surface` → `--rr-surface-raised` → стекло | пять слоёв: стол → утопленное → бумага → поднятое → стекло |
| `--rr-ink` / `--rr-ink-2` / `--rr-ink-3` | текст / вторичный смысл / плейсхолдеры и подсказки ≤13px (ink-3 — только на surface и surface-2) |
| `--rr-line` / `--rr-line-strong` | hairline / границы полей и дропзон |

| `--rr-accent-2` / `--rr-accent-2-text` / `--rr-accent-2-soft` | маркер «сейчас здесь»: на индиго — **белый** (`#ffffff`; до 13.09.2026 была аква `#95fbf2`, владелец убрал — резала глаз); на белой бумаге — `-text` (тил) и `-soft` (мягкая подложка) |
| `--rr-ink-surface` / `--rr-ink-surface-text` / `--rr-ink-surface-line` | индиго-карточка отсчёта 5 с и undo-бар |
| `--rr-shadow-1` / `--rr-shadow-2` / `--rr-shadow-ink` | мягкий 3D бумаги / поднятого / индиго-объекта. Все три — одного цвета (чернила стола): цветного ореола под индиго нет, иначе объект читается неоном |
| `--rr-object` | заливка единственного цветного объекта экрана (рельс / плита / поднос); днём `2nd → accent → deep`, ночью `2nd → deep` — оба края темнее `accent` |
| `--rr-primary-grad` / `-hover` | заливка primary-кнопки; ночью своя пара, чтобы белая подпись держала ≥4.5:1 на светлом крае градиента |
| `--rr-shot-dim` / `--rr-shot-line` | чужой светлый экран в `rr-shot`: днём без фильтра, ночью приглушён и обведён |
| `--rr-{wait,work,muted,ok,danger}-{bg,ink,dot}` | статус-пилюли, точки, штампы |
| `--sp-1…12`, `--fs-12…28` + `--rr-fs-32/40` + `--lh-*` | отступы (4px), типографика |
| `--rr-r-{xs,sm}` 8 / `--rr-r-md` 14 / `--rr-r-{lg,xl}` 24 | три ступени радиуса по вложенности; `lg` и `xl` намеренно равны |
| `--dur-fast` / `--dur` / `--dur-slow`, `--rr-dur-page/-theme/-stamp`, `--rr-ease-*`, `--undo-ms` | движение 120 / 200 / 260, страница 280, тема 480, штамп 340, окно отмены 5 с |
| `--rr-container` 1360 / `--rr-container-wide` 1600 / `--rr-rail-w` 272 / `--rr-bar-h` 60 | сетка |

Тёмная тема «Arc · ночь» (стол `#0d0f1c`, индиго светлее `#5b6fe6`, индиго-объект темнее primary через `--rr-accent-deep`, маркер тот же белый, тил приглушён) — тот же список ролей в блоке `[data-theme='dark']`. Ночью бумага `#1e2240` светлее стола примерно на 9 ступеней L*, поэтому карточка видна пятном, а не рамкой; утопленное `#171a30` темнее бумаги — порядок слоёв тот же, что днём; мягкий 3D держит верхний блик 1 px белого 8 % в `--rr-shadow-1/2`. Скрин заказчика светлый по своей природе: ночью он приглушается `--rr-shot-dim` и обводится `--rr-shot-line`, иначе он ярче любой бумаги. `ThemeService` ставит атрибут, тумблер день/ночь в шапке переключает с круговым раскрытием от ручки (View Transitions, круг — WAAPI литералами); пункта темы в меню аватара нет — «как в системе» действует до первого клика. Светлая остаётся основной: скрины с проектора показываем в ней.

**Закон маркера.** На индиго маркер белый и тихий: активный пункт рельса — стекло (белый 18 % + блик 1px сверху, текст белый, без ореола), число рельса, точка пилюли статуса в шапке карточки, полоска и цифра отсчёта 5 с. На белой бумаге — тил: точка бренд-знака, активный шаг строки пути, кольцо кадра «Дифф», кружок заказчика в «Смотрят» (`-soft` подложкой). Яркой заливки поверх индиго нет; никогда — цветной фон кнопки на белом, абзацный текст, точки у каждого статуса в списках. Второй залитый индиго-объект на экране запрещён (primary-кнопка не в счёт). Тумблер темы: небо/солнце/луна своей палитрой `--rr-tt-*` (референс владельца).

Шрифты: **Onest** (интерфейс) + **Unbounded** (display: wordmark, номер в шапке карточки 40, число тихого тайла 40, число плиты «Ждут вас» 104, счётчик подноса 44, номера строк 15). Оба self-hosted через `@fontsource-variable`. Базовый кегль 15/22; h1 32/700; заголовок карточки 28/700; лид 18/600; подзаголовок страницы 14 ink-3; eyebrow 12 uppercase — только заголовки колонок.

## Иерархия

- **Журнал** = сводка раунда: сетка 6 колонок — индиго-плита «Ждут вас» на две колонки (число Unbounded 104 сидит на нижнем паддинге в одну линию с белой кнопкой «Начать разбор» в правом нижнем углу) + четыре тихих тайла без тени, у всех подпись сверху, а число с подстрокой — внизу; подписи тайлов 13 обычным регистром; чип «Новые желания» стоит в строке шапки таблицы, отдельной полосы над ней нет; таблица «№ · Суть · Итог · Статус» — `table-layout: fixed`, доли **8 / 38 / 34 / 20 %**, строка 64px, номер Unbounded, миниатюра прижата к правому краю «Сути» (слот в строках без скрина не резервируется: заголовки и так стоят в одной вертикали, а сама миниатюра закрывает пустоту перед «Итогом»), «Итог» 15/500 ink и никогда не «—», статус — слово без точки; в фильтре «Все» — группы «Ждут вас» (индиго-полоса) / «Остальные». Схемы и подсказок на журнале нет.
- **Карточка** живёт рядом с **индиго-рельсом очереди** «i из N» (272px, скрыт < 1280; верх выровнен с бумагой, высота — колонка ≈560px, «i из N» прижато к низу; подпись рельса — 13 обычным регистром; активный — стекло: белый 18 %, текст белый; без точек и пагинации). «Следующее ›» в строке навигации вычитает свой паддинг и стоит ровно на правом крае бумаги. Шапка: номер Unbounded 40 индиго на базовой линии заголовка 28/700, пилюля статуса индиго с белой точкой, мета, строка пути «• Замечание • Разбор • Решение…» без линий. Колонки `1.1fr 1fr 0.9fr`: Улики (скрин-герой 16:10 или дропзона, «Со слов заказчика» — тонированный блок без рамки) | Черновик разбора (первой строкой — вывод «Похоже, это…», затем «На скрине видно», цитаты — редакторские врезки: линия 2px индиго слева, без плашки, затем пояснение; лента фаз только пока сервер в `running`) | Ваше решение (подложки у панели нет — она лежит прямо на бумаге; подписи групп 13 обычным регистром; варианты — одна стопка листов в обойме 14 со встречными линиями, кей-капы 1–5; группа «это работа» — залитая primary своей формой; совет разработчика — подпись строкой в кнопке, без плашки). Ретест и ожидание кадра — две колонки `2.1fr 0.9fr`: сцена сравнения с «Дифф» по умолчанию (кольцо тилом) и табами-миниатюрами.
- **Капс с разрядкой на карточке** носят только три заголовка колонок — «Улики · Черновик разбора · Ваше решение». Всё остальное (подпись рельса, «Со слов заказчика», «Что сделать», подписи групп решения) — 13 обычным регистром.
- **Отсчёт 5 с** — индиго-карточка: «Решение: … · Отменить (Esc) · 5…1» белой полоской, «Следующее» подписано «Решение уйдёт сразу»; переходы →/← и рельс заблокированы, пока отсчёт идёт.
- **Решение записано** — штамп (`rr-stamp`, наклон −2°, без фактуры) + «кто · когда» + primary «Следующее → № N».
- Шапка — плавающая белая полоса со скруглением 24 (отступ 12 сверху): бренд-знак + RemarkRound · контекст «Проект · Раунд ▾» | сегменты разделов без капсулы (активный — мягкая индиго-подложка; у разработчика с одним разделом сегментов нет) | «Добавить замечание» · тумблер день/ночь · тихий аватар (surface-2, буква цветом роли). Один h1 на страницу.
- **Очередь разработчика**: «В работе» — индиго-поднос (единственный цветной объект); подпись 22/600 и счётчик Unbounded 44 стоят на одной базовой линии, строки лежат на подносе белыми листами (миниатюра 112×70 — высоту листа задаёт текст), кнопка «Готово, можно смотреть снова» — выпуклая белая с индиго-текстом; остальные группы — плоские списки на столе с капс-заголовком 13; подсказки и повторы счётчиков вырезаны.
- **Раунды** (ADR 011) — архив, а не очередь: цветного объекта нет. Шапка страницы + вторичная «Выгрузить журнал (.xlsx)»; одна бумага-таблица «№ · Раунд · Замечания», свежий раунд сверху, строка 72px ведёт в журнал раунда; номер Unbounded, под «Раунд N» — «идёт с …» (тил, маркер «сейчас здесь») или «закрыт … · кто (роль)» ink-3; справа текстовая «Выгрузить (.xlsx)». **Закрытый раунд в журнале** — плашка-факт тоном «закрыто» (ok-bg, радиус 14, без рамки): «Раунд 2 закрыт 10 сент. 2026 · Дана (руководитель приёмки) · только чтение» + «Все раунды»; «Добавить замечание», «Связать с №», импорт — скрыты или неактивны.
- **Страницы-формы** (Документы, Импорт, Новое замечание, Профиль) — одна сетка из равных колонок на страницу, зазор 24, ряды тянутся до одной высоты, кнопки карточек прижаты к низу; ≤ 900 — одна колонка. **Документы** — `repeat(3)`: полка ТЗ · Протокол · Доп. соглашение (последняя версия карточкой с «Новая версия» или дропзона своего типа — переключателя типа нет), «Ещё в пакете» — прежние версии, внизу поиск на две колонки + «Зачем документы». **Импорт** — `repeat(3)`: дропзона 1 + «Что в шаблоне» 2, ниже три шага тайлами ровно под колонками. **Новое замечание** — `repeat(2)`: форма | дропзона (tall, 24 — лежит на столе) или превью + «Что будет дальше», низ правой колонки вровень с формой. **Профиль** — полоса «кто я» (буква 72, имя, почта, проекты и роли; половины полосы стоят над содержимым карточек) + две карточки «Данные» | «Пароль».

## Движение

Движение — ответ на действие человека или событие сервера (`styles/motion.css`): переход страниц crossfade 280ms и серифный номер перетекает из строки журнала в шапку карточки; появление списков лестницей 30ms×индекс; hover-подъём бумаги на 1px; primary с бликом и тенью, active scale .98; тема — круговое раскрытие от кнопки 480ms; штамп ложится с пружиной 340ms; лента фаз — по реальным WS-событиям; дропзона реагирует на drag/paste. Печати по буквам нет. `prefers-reduced-motion` гасит всё.

## Angular

- Без Material/CDK, без библиотек анимаций и иконок (`ui/icons.ts` — свой набор из 24).
- `withViewTransitions()` в `app.config.ts`; флаг `vtActive` (`core/view-transitions.ts`) — две VT одновременно не бывает.
- Клавиши — `core/shortcuts.service.ts` по `event.code`; не срабатывают в полях, на слайдере, при открытом просмотрщике/меню.
- Фокус: видимое кольцо; `outline: none` без замены запрещён.

## Адаптив

Desktop-first: 1440 и 1920 — основные. Брейкпоинты единые: 1280 (рельс виден), 900 (нижний таб-бар, колонки в столбик, панель решения липнет снизу). Ниже 900 ничего не ломается, но логика построена для десктопа.
