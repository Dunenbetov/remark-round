# VISUAL.md — «Arc · Индиго»: белая бумага, один цветной объект

Не Linear. Не ChatGPT. Не фиолетовая админка. Не бумажный гроссбух.  
Направление выбрано владельцем 11 сентября 2026 из четырёх макетов (Arc/Raycast + Bento); процесс — по статье Anshu Chimala: seed-строки → макеты → критик-субагент по скриншотам → вырезать лишнее. Живой эталон — само приложение (`apps/web`); `reference.html` и «стол с бумагами» — история.

## Ощущение

Светлый прохладный стол, белая бумага с мягким 3D (тень вниз, блик сверху), скругления 14 / 20 / 24. На каждом экране ровно один большой цветной объект — индиго: рельс очереди на карточке, тайл «Ждут вас» в журнале, поднос «В работе» в очереди разработчика. Аква — только «сейчас здесь». Ничего не объясняет само себя дважды: подсказок-строк и схем в потоке нет, критик их вырезал. Можно читать с проектора на защите.

## Токены

Единственный источник — [`apps/web/src/styles/tokens.css`](../../apps/web/src/styles/tokens.css). Роли, не хексы:

| Роль | Зачем |

| `--rr-bg` → `--rr-surface-2` → `--rr-surface` → `--rr-surface-raised` → стекло | пять слоёв: стол → утопленное → бумага → поднятое → стекло |
| `--rr-ink` / `--rr-ink-2` / `--rr-ink-3` | текст / вторичный смысл / плейсхолдеры и подсказки ≤13px (ink-3 — только на surface и surface-2) |
| `--rr-line` / `--rr-line-strong` | hairline / границы полей и дропзон |
| `--rr-accent` / `--rr-accent-2nd` / `--rr-accent-deep` / `--rr-accent-text` / `--rr-accent-soft` | **индиго** `#1d2d80` — цвет решения и большого объекта: primary-кнопка (градиент `2nd → accent`), рельс / тайл / поднос (градиент `2nd → accent → deep`), пилюля статуса в шапке карточки |
| `--rr-accent-2` / `--rr-accent-2-text` / `--rr-accent-2-soft` | **аква** `#95fbf2` — «сейчас здесь»; применения по закону аквы (комментарий в tokens.css); как текст на белом — только `-text` (тил) |
| `--rr-ink-surface` / `--rr-ink-surface-text` / `--rr-ink-surface-line` | индиго-карточка отсчёта 5 с и undo-бар |
| `--rr-shadow-1` / `--rr-shadow-2` / `--rr-shadow-ink` | мягкий 3D бумаги / поднятого / индиго-объекта |
| `--rr-{wait,work,muted,ok,danger}-{bg,ink,dot}` | статус-пилюли, точки, штампы |
| `--sp-1…12`, `--fs-12…28` + `--rr-fs-32/40` + `--lh-*`, `--rr-r-{xs,sm,md,lg,xl,pill}` | отступы (4px), типографика, радиусы |
| `--dur-fast` / `--dur` / `--dur-slow`, `--rr-dur-page/-theme/-stamp`, `--rr-ease-*`, `--undo-ms` | движение 120 / 200 / 260, страница 280, тема 480, штамп 340, окно отмены 5 с |
| `--rr-container` 1360 / `--rr-container-wide` 1600 / `--rr-rail-w` 240 / `--rr-bar-h` 60 | сетка |

Тёмная тема «Arc · ночь» (`#0f1120`, индиго светлее `#5b6fe6`, индиго-объект темнее primary через `--rr-accent-deep`, аква та же) — тот же список ролей в блоке `[data-theme='dark']`; `ThemeService` ставит атрибут, тумблер день/ночь в шапке переключает с круговым раскрытием от ручки (View Transitions, круг — WAAPI литералами); пункта темы в меню аватара нет — «как в системе» действует до первого клика. Светлая остаётся основной: скрины с проектора показываем в ней.

**Закон аквы.** Аква живёт только на индиго или как маркер: активный элемент рельса (заливка аквой, текст индиго), точка пилюли статуса в шапке карточки и бренд-знака (тил), полоска и цифра отсчёта 5 с, кольцо кадра «Дифф» (тил). Никогда — фон кнопки на белом, абзацный текст, точки у каждого статуса в списках. Второй залитый индиго-объект на экране запрещён (primary-кнопка не в счёт). Тумблер темы: небо/солнце/луна своей палитрой `--rr-tt-*` (референс владельца).

Шрифты: **Onest** (интерфейс) + **Unbounded** (display: wordmark, номер в шапке карточки 40, число тайла 40/56, счётчик подноса 40, номера строк 15). Оба self-hosted через `@fontsource-variable`. Базовый кегль 15/22; h1 32/700; заголовок карточки 28/700; лид 18/600; подзаголовок страницы 14 ink-3; eyebrow 12 uppercase — только заголовки колонок.

## Иерархия

- **Журнал** = сводка раунда: сетка 6 колонок — индиго-тайл «Ждут вас» на две колонки (число Unbounded 56, белая кнопка «Начать разбор» в правом нижнем углу) + четыре тихих тайла без тени; таблица «№ · Суть · Итог · Статус» (строка 64px, номер Unbounded, слот миниатюры зарезервирован в каждой строке — заголовки в одной вертикали, «Итог» 15/500 ink и никогда не «—», статус — слово без точки); в фильтре «Все» — группы «Ждут вас» (индиго-полоса) / «Остальные». Схемы и подсказок на журнале нет.
- **Карточка** живёт рядом с **индиго-рельсом очереди** «i из N» (272px, скрыт < 1280; верх выровнен с бумагой; активный — аква; без точек и пагинации). Шапка: номер Unbounded 40 индиго на базовой линии заголовка 28/700, пилюля статуса индиго с аква-точкой, мета, строка пути «• Замечание • Разбор • Решение…» без линий. Колонки `1.1fr 1fr 0.9fr`: Улики (скрин-герой 16:10 или дропзона, «Со слов заказчика» — тонированный блок без рамки) | Черновик разбора (первой строкой — вывод «Похоже, это…», затем «На скрине видно», цитаты — тонированные индиго-блоки без рамки, затем пояснение; лента фаз только пока сервер в `running`) | Ваше решение (утопленная панель `surface-2` без рамки, подписи групп 13 обычным регистром, кнопки-листы с кей-капами 1–5, одна primary с градиентом). Ретест и ожидание кадра — две колонки `2.1fr 0.9fr`: сцена сравнения с «Дифф» по умолчанию (кольцо тилом) и табами-миниатюрами.
- **Отсчёт 5 с** — индиго-карточка: «Решение: … · Отменить (Esc) · 5…1» аква-полоской, «Следующее» подписано «Решение уйдёт сразу»; переходы →/← и рельс заблокированы, пока отсчёт идёт.
- **Решение записано** — штамп (`rr-stamp`, наклон −2°, без фактуры) + «кто · когда» + primary «Следующее → № N».
- Шапка — плавающая белая полоса со скруглением 20 (отступ 12 сверху): бренд-знак + RemarkRound · контекст «Проект · Раунд ▾» | сегменты разделов без капсулы (активный — мягкая индиго-подложка; у разработчика с одним разделом сегментов нет) | «Добавить замечание» · тумблер день/ночь · тихий аватар (surface-2, буква цветом роли). Один h1 на страницу.
- **Очередь разработчика**: «В работе» — индиго-поднос (единственный цветной объект) со счётчиком Unbounded 40, строки лежат на нём белыми листами, кнопка «Готово, можно смотреть снова» — выпуклая белая с индиго-текстом; остальные группы — плоские списки на столе с капс-заголовком 13; подсказки и повторы счётчиков вырезаны.

## Движение

Движение — ответ на действие человека или событие сервера (`styles/motion.css`): переход страниц crossfade 280ms и серифный номер перетекает из строки журнала в шапку карточки; появление списков лестницей 30ms×индекс; hover-подъём бумаги на 1px; primary с бликом и тенью, active scale .98; тема — круговое раскрытие от кнопки 480ms; штамп ложится с пружиной 340ms; лента фаз — по реальным WS-событиям; дропзона реагирует на drag/paste. Печати по буквам нет. `prefers-reduced-motion` гасит всё.

## Angular

- Без Material/CDK, без библиотек анимаций и иконок (`ui/icons.ts` — свой набор из 24).
- `withViewTransitions()` в `app.config.ts`; флаг `vtActive` (`core/view-transitions.ts`) — две VT одновременно не бывает.
- Клавиши — `core/shortcuts.service.ts` по `event.code`; не срабатывают в полях, на слайдере, при открытом просмотрщике/меню.
- Фокус: видимое кольцо; `outline: none` без замены запрещён.

## Адаптив

Desktop-first: 1440 и 1920 — основные. Брейкпоинты единые: 1280 (рельс виден), 900 (нижний таб-бар, колонки в столбик, панель решения липнет снизу). Ниже 900 ничего не ломается, но логика построена для десктопа.
