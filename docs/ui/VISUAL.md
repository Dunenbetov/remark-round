# VISUAL.md — стол с бумагами, доведённый до крафта

Не Linear. Не ChatGPT. Не фиолетовая админка.  
Редизайн «Инбокс приёмки» (сентябрь 2026): план и спецификация — `~/.claude/plans/dapper-yawning-kay.md`; живой эталон — само приложение (`apps/web`), `reference.html` рядом устарел и оставлен как история.

## Ощущение

Тёплый бумажный стол, дело из улик, спокойные кнопки человека. Много воздуха, но пустота заполнена данными, которые уже есть в API, а не декором. Можно читать с проектора на защите.

## Токены

Единственный источник — [`apps/web/src/styles/tokens.css`](../../apps/web/src/styles/tokens.css). Роли, не хексы:

| Роль | Зачем |
|---|---|
| `--rr-bg` → `--rr-surface-2` → `--rr-surface` → `--rr-surface-raised` → стекло | пять слоёв: стол → утопленное → бумага → поднятое → стекло |
| `--rr-ink` / `--rr-ink-2` / `--rr-ink-3` | текст / вторичный смысл / плейсхолдеры и подсказки ≤13px (ink-3 — только на surface и surface-2) |
| `--rr-line` / `--rr-line-strong` | hairline / границы полей и дропзон |
| `--rr-accent` / `--rr-accent-text` / `--rr-accent-soft` | сосновый — **цвет решения**: заливка primary / ссылки / фон soft-кнопки |
| `--rr-accent-2` / `--rr-accent-2-text` / `--rr-accent-2-soft` | **медь — «ждёт человека»**; применения строго по закону меди (комментарий в tokens.css) |
| `--rr-ink-surface` / `--rr-ink-surface-text` / `--rr-ink-surface-line` | чернильная карточка отсчёта (в тёмной теме — светлая) |
| `--rr-{wait,work,muted,ok,danger}-{bg,ink,dot}` | статус-пилюли, точки, штампы |
| `--sp-1…12`, `--fs-12…28` + `--rr-fs-32/40` + `--lh-*`, `--rr-r-{xs,sm,md,lg,xl,pill}` | отступы (4px), типографика, радиусы |
| `--dur-fast` / `--dur` / `--dur-slow`, `--rr-dur-page/-theme/-stamp`, `--rr-ease-*`, `--undo-ms` | движение 120 / 200 / 260, страница 280, тема 480, штамп 340, окно отмены 5 с |
| `--rr-container` 1360 / `--rr-container-wide` 1600 / `--rr-rail-w` 240 / `--rr-bar-h` 60 | сетка |

Тёмная тема — тот же список ролей в блоке `[data-theme='dark']`; `ThemeService` ставит атрибут, тумблер день/ночь в шапке переключает с круговым раскрытием от ручки (View Transitions, круг — WAAPI литералами); пункта темы в меню аватара нет — «как в системе» действует до первого клика. Светлая остаётся основной: скрины с проектора показываем в ней.

**Закон меди.** Медь — только маркеры (3px полоса «ждут вас», активный элемент рельса, маркер тайла, точка бренд-знака), рамка кадра «Дифф», крупное число тайла и текст ≥13px/600, полоска отсчёта, аватар роли business. Никогда — фон кнопки, пилюли, чипа, абзацный текст. Решение — всегда сосновый. Единственное исключение — тумблер темы: небо/солнце/луна своей палитрой `--rr-tt-*` (референс автора), меди там нет.

Шрифты: **Golos Text** (интерфейс) + **Source Serif 4** — «голос документов»: wordmark, «№ 12» карточки, номера строк, текст цитаты ТЗ. Оба self-hosted. Базовый кегль 15/22; h1 32/700; лид 18/600; eyebrow 12 uppercase.

## Иерархия

- **Журнал** = сводка раунда: пять тайлов-фильтров («Ждут вас · В работе · На ретесте · Закрыто · Все») + кнопка «Начать разбор»; таблица «№ · Суть · Итог · Статус» (строка 72px, серифный номер, миниатюра только когда скрин есть, «Итог» никогда не «—»); в фильтре «Все» — группы «Ждут вас / Остальные».
- **Карточка** живёт рядом с **рельсом очереди** «i из N» (240px, скрыт < 1280). Колонки `1.1fr 1fr 0.9fr`: Улики (скрин-герой 16:10 или дропзона, «Со слов заказчика») | Черновик разбора (серифная цитата ≥ стрима; лента фаз только пока сервер в `running`) | Ваше решение (три группы «Это работа / Это не работа / Нужны данные», одна primary, клавиши 1–5, комментарий свёрнут). Ретест и ожидание кадра — две колонки `2.1fr 0.9fr`: сцена сравнения с «Дифф» по умолчанию (рамка медью) и табами-миниатюрами.
- **Отсчёт 5 с** — чернильная карточка: «Решение: … · Отменить (Esc) · 5…1» медной полоской, «Следующее» подписано «Решение уйдёт сразу»; переходы →/← и рельс заблокированы, пока отсчёт идёт.
- **Решение записано** — штамп (`rr-stamp`, наклон −2°, без фактуры) + «кто · когда» + primary «Следующее → № N».
- Шапка 60px: бренд-знак + RemarkRound · одна контекст-пилюля «Проект · Раунд ▾» | сегменты разделов (Журнал ·N) | «Добавить замечание» · тумблер день/ночь · аватар. Один h1 на страницу: фраза роли (Журнал, Очередь) или имя раздела (Документы, Импорт — роль в eyebrow).

## Движение

Движение — ответ на действие человека или событие сервера (`styles/motion.css`): переход страниц crossfade 280ms и серифный номер перетекает из строки журнала в шапку карточки; появление списков лестницей 30ms×индекс; hover-подъём бумаги на 1px; primary с бликом и тенью, active scale .98; тема — круговое раскрытие от кнопки 480ms; штамп ложится с пружиной 340ms; лента фаз — по реальным WS-событиям; дропзона реагирует на drag/paste. Печати по буквам нет. `prefers-reduced-motion` гасит всё.

## Компоненты, которых нет

## Angular

- Без Material/CDK, без библиотек анимаций и иконок (`ui/icons.ts` — свой набор из 24).
- `withViewTransitions()` в `app.config.ts`; флаг `vtActive` (`core/view-transitions.ts`) — две VT одновременно не бывает.
- Клавиши — `core/shortcuts.service.ts` по `event.code`; не срабатывают в полях, на слайдере, при открытом просмотрщике/меню.
- Фокус: видимое кольцо; `outline: none` без замены запрещён.

## Адаптив

Desktop-first: 1440 и 1920 — основные. Брейкпоинты единые: 1280 (рельс виден), 900 (нижний таб-бар, колонки в столбик, панель решения липнет снизу). Ниже 900 ничего не ломается, но логика построена для десктопа.
