Приложение

Трейсинг, защита, ограничения

Трейсинг

Langfuse Cloud. Один прогон, один трейс: traceId = sha256(runId).

Счёт Langfuse на 17 % ниже нашего прайса: кэш промпта.

Защита

Детектор инъекций по тексту, 15 правил.

Черновик проверяет код. Фильтр проекта в SQL. Закрывает только заказчик.

Ограничения

Один инстанс API.

Кадры разного размера не сравниваются.

Детектор не читает кадр. Golden синтетический.

Полный список ограничений с доказательствами: docs/defense/HONEST-NOTES.md. Соответствие требованиям курса: таблица в README.
