Единица цитаты: раздел ТЗ, PM видит «§2.1 Primary». Фильтр проекта стоит в SQL, не в промпте. Reranker не ставили: classify получает до 8 фрагментов целиком и сам указывает опоры, код отбрасывает id не из выдачи. Слабое место: точные токены вроде hex-цвета. Корпус маленький, это ограничение замера. Мультимодальность. Ретест: алгоритм сравнивает пиксели, модель смотрит три кадра (было, стало, дифф) и поясняет. Без модели ни одно из трёх настоящих исправлений не узнаётся. Разбор: факты кадра идут в classify, черновик и переписанный запрос, если он нужен. В кейсе, где текст заказчика расходится с экраном, с картинкой верно 15 прогонов из 16, без неё 0 из 1. Второй такой кейс не решается и с картинкой, 0 из 16: факты кадра верные, ошибается classify. Прогон без картинки один, и промпт в нём ещё говорил «кадр есть», поэтому это не оценка вклада картинки. Чистую абляцию не делали.
