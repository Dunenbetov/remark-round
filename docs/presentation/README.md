PDF собирается из `slides/*.html` скриптом `docs/presentation/build-pdf.mjs`: из корня репозитория `node docs/presentation/build-pdf.mjs`. Нужен Google Chrome и `pnpm install` (шрифты Onest и Unbounded берутся из пакетов `apps/web`). Заметки докладчика в PDF не попадают.
